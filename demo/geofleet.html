1. Choose an assumed link failure

Operator rule: disconnect simulated devices inside the rectangle, including its boundary. Not a claim that those places lost power. All dots are fictitious abstract points, not addresses or Base deployments.

100 synthetic batteries: 5 kW limit, 3 kWh capacity, 1 kWh protected reserve each. Target: 400 kW for 600 seconds. Ten start near reserve. These are not actual Base battery specifications.

Communication loss ≠ stopped discharge. Last commands may persist until the assumed local stop. Physical grid outage is not modeled. Energy depletion to reserve is separate.

What this model assumes

Guaranteed local stops: each battery stops within 30 or 40 seconds after its last command. The policy uses the 40-second bound. We assume instant acknowledgements and exact, noiseless energy readings. The local plant protects backup reserve for both policies, not just the redistribution policy.

Discharge only, 100% efficiency. No household demand, charging, grid limits or physical outage. Those assumptions need to be replaced and tested before a production implementation.

      5. Experimental: command and telemetry uncertainty
      

      Separate experimental surface. It does not change the offline controller check above, its registry or its verdicts. It runs the experimental almanac.uncertainty simulator directly over a closed registry of small bounded synthetic scenarios that exercise acknowledgement loss, acknowledgement delay and reconnect backfill. The model is synthetic and uncalibrated, and no production safety verdict is produced here: nothing in this section clears, ranks or certifies any controller, policy or device. The same registry runs on the command line: python -m almanac.uncertainty_lab run --experiment <key>.
      

      Command received
      Evaluator truth: the simulated device holds the command. The controller cannot see this.
      Acknowledged
      The only confirmation the controller has. A lost or late acknowledgement withholds it while the device keeps running the command.
      Telemetry freshness
      A property of the link and the clock: reporting, late or unreachable. Fresh telemetry is not an acknowledgement.

      Command expiry is an absolute TTL on simulated wall time: it keeps running through an outage, a reconnect never restarts it, and the boundary second is already expired. Reserve is an energy floor inside the simulation, held by a clamp local to the simulated device, and it is not evidence that any household, load or site stayed powered. Every input is invented, including the loss and delay schedules, so no failure rate, probability or risk frontier is claimed. This section accepts registered experiment keys only: no scenario file, no import path, no filesystem path and no uploaded code.
